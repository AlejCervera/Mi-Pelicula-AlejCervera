# Aplicación gimnasio | Mi Película - Alejandro Cervera Alcalá

Aplicación para registrar mis entrenamientos de gimnasio (ejercicios, pesos,
series y repeticiones) y, a largo plazo, recibir recomendaciones basadas en IA.

## Motivación
Me estoy empezando a tomar enserio el gimansio y muchas de las apps son de pago y no puedo tener acceso total a ellas, por lo que quiero crear la mía propia.

## Estado actual
Versión 0.1: script de consola que guarda series en un CSV.

## Formato de los datos
Una fila por serie: fecha, ejercicio, serie, peso_kg, reps.
